SNES Emulator (JS Core)

Play your own SNES ROMs directly in the browser – no installs, just upload and play.

SNES Player Pure JavaScript Core

Load your own .smc or .sfc ROMs inside the emulator below. If audio doesn’t start, click once inside the game area to let the browser unlock sound.

How to Use

  • Click inside the emulator frame.
  • Use its built-in menu to load your ROM file.
  • Play with keyboard controls (shown in the emulator UI).

Keyboard (Typical Mapping)

  • Arrows → D-Pad
  • Enter → Start   /   Shift → Select
  • Z/X/S/A/D/C → Face & shoulder buttons (varies by core)
Core powered by the open-source project SnesJs (pure JavaScript SNES emulator, MIT license). This page only wraps it with the FileConverter.run interface.
