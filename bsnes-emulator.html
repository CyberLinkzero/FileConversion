Keyboard controls (Player 1)

D-Pad: ↑ ↓ ← →  |  B: Z   A: X  |  Y: A   X: S  |  L: Q   R: W  |  Start: Enter   Select: Right Shift

Gamepad: Plug in a controller (Xbox / PS / generic). The first connected gamepad is mapped using the standard layout: B=A button, A=B button, X=X, Y=Y, LB=L, RB=R, Start=Start, Back=Select.

Notes: This page is just the UI shell. The bsnes core comes from libs/bsnes-core.js, which must expose window.startBSNES(romBytes, canvas, options). Save states and SRAM are stored in localStorage keyed by ROM name+size.

Runs entirely in your browser. No ROMs are uploaded or stored on any server.
