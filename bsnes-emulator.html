SNES Emulator (EmulatorJS)

Play SNES ROMs with controller support, fullscreen, sound, and save states – all in your browser.

SNES Player RetroArch Core via EmulatorJS

💾 This page auto-loads a SNES ROM from your FileConverter.run repo. Click inside the game window to unlock sound, then use the EmulatorJS menu to manage save states, controls, and fullscreen.

How to Use

  • Upload your ROM file (e.g. mygame.smc) into /FileConversion/roms/ on GitHub.
  • Update the ROM URL in the script at the bottom of this file.
  • Reload this page. After it loads, click once in the game window (audio unlock), and the game should start.

Keyboard & Controller

  • Arrows → D-Pad
  • Enter → Start   /   Shift → Select
  • Z / X / A / S → Face buttons (default)
  • Plug in an Xbox / PS / USB pad → configure in Control Settings inside the emulator menu.
Emulator powered by EmulatorJS (RetroArch cores in the browser, with save states, controller mapping, and fullscreen).
