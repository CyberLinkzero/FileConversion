Emulator Options & Features

1. Load Your ROM

  • Click once inside the emulator window (to focus & unlock sound).
  • Use the emulator’s menu (usually a ☰ / menu icon or right-click) and choose Load Game / Load ROM.
  • Select your .smc or .sfc file from your computer.

If you see a “network error” inside the emulator, it usually means it tried to auto-load a demo ROM from the web and couldn’t. Just use the Load ROM option and pick your own file.

2. Controller & Keyboard

Controller plugins Keyboard mapping Virtual gamepad (mobile)
  • Plug in your Xbox / PlayStation / USB controller.
  • Open the emulator menu > Controls / Input / Gamepad.
  • Map each SNES button (A, B, X, Y, L, R, Start, Select, D-pad) to your controller.
  • On keyboard, default bindings are usually:
    • Arrows → D-Pad
    • Enter → Start   /   Shift → Select
    • Z / X / A / S → Face buttons

3. Sound & Video Settings

Volume / mute fullscreen Scaling / filters
  • Use the emulator’s Audio / Settings menu to adjust volume and mute.
  • Use the built-in Fullscreen button or your browser fullscreen (F11) for a bigger view.
  • Some cores expose video filters (scanlines, smoothing) in the Video menu.

The Fullscreen Browser button enlarges the whole page. The emulator’s own fullscreen option can also be used inside its menu.

4. Save States & Local Saves

Save state slots Load state Persistent saves
  • Use the emulator menu > Save State to capture your current game position.
  • Use Load State to jump back instantly.
  • Many EmulatorJS frontends allow exporting / importing state files, and some store SRAM in browser storage.

5. Performance Tips

  • Close extra heavy tabs (YouTube, streaming, etc.).
  • Use a Chromium-based browser (Chrome / Edge / Brave) for best WASM performance.
  • On laptops, disable battery saver so the CPU/GPU aren’t throttled.
